# sport-vernacular-craft

1. Run **sport-site-research** first — refuse to invent a sport UI from a generic sports moodboard
2. Load `getSportPack(sportId)` from `@tell/design-skills`
3. Paint **primaryFacts** in order on the glance surface (inverted pyramid)
4. Apply the active **formatLens** (emphasize / demote)
5. Keep the score spine **layout-stable**; use tabular numerals
6. Separate **glance-live** from **sit-with** editorial chapters
7. Model **technicalConcepts** honestly (reviews, extras, stoppage, challenges)
8. Use **materialVernacular** for atmosphere — not sticker decoration
9. Honor Taste seed from the pack unless the brief overrides
10. Offer Taste Controls at the end

## Avoid

- Same layout for Test and T20
- Card grids that equalize score, ad, and fantasy
- Color-only wicket/boundary encoding
- Heavy hero imagery before score paint on mobile
- Naming third-party sports portals in committed artifacts
