# conversion-landing-craft

A landing page is not a homepage. Win **one intent**: one offer → one audience → one primary action.

## Gather before generating

1. **Primary action** — trial, demo, waitlist, buy (exactly one above the fold)
2. **Offer** — what they get in plain words
3. **ICP + pain** — who, and why they have not converted
4. **Proof** — only declared logos/metrics/features; omit inventing any
5. **Risk reversal** — trial, cancel anytime, or talk-to-human (pick one honest option)

## Structure (Tell engine maps these)

| Band | Job |
|---|---|
| Hero | Outcome headline + how subhead + one CTA + product stage |
| Workflow / proof | Mechanism evidence (`product-proof-stage`) |
| Benefits | 3–5 outcome bullets from declared features |
| How it works | 3–5 steps (story chapters) |
| Pricing / compare | Only when ≥3 capabilities |
| FAQ | 6–8 objection answers (not feature reprints) |
| Final CTA | Same verb as hero + risk note |

## Copy rules

- Benefit-first; specificity over “streamline / optimize”
- CTA = verb + what they get (`Book a demo`, not `Learn more`)
- One primary CTA above the fold; secondary quieter
- FAQ answers scope, sequencing, limits, cancel/risk — never re-explains the catalogue

## Layout picks

- **Classic hero + sections** — default for understandable products (`saas-marketing`)
- **Long-form story** — high skepticism (`corporate-story`, `refined-story`)
- **Minimal conversion** — high-intent traffic (sparse density)
- **Comparison** — when procurement needs a matrix

## Validate

- Mobile readable; focus-visible; reduced motion safe
- No competing CTAs in the fold
- Tell diagnose when available — generic SaaS tells should drop

## Runtime

Routed for `saas-marketing`. FAQ + CTA risk notes emit from `@tell/design-skills` copy helpers.
