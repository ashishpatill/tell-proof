# container-tech-shell

## Visual target (learned)

- Near-dark or paper base with **large framed containers** defining composition
- Containers drive hierarchy: bordered shells, inset panels, side rails, corner squares
- Technical structure: thin borders, vertical frame lines, measured spacing
- Optional focal energy (glow, ring, underlight) tied to **brand accent**, not a fixed hue family
- Clean type + mono utility labels

## Implementation

1. Centered max-width master container with visible outer boundaries
2. Layered treatments: framed cards, optional soft gradient edge, translucent panels when `glass-shell-craft` allows one shell
3. Corner markers / rails (pairs with `split-panel-technical` brackets)
4. Motion: masked reveals, slow pulse on focal glow only — pause offscreen / reduced-motion

## Tuning knobs

Accent mood from brandAccent; roundness vs crisp frames; funk factor (focal objects); lighting concentrated on hero; structure density of rails/corners

## Tell remap

- Default accent = Taste `brandAccent` / `--c-accent` (never hardcode fuchsia/violet)
- SaaS conversion still prefers product-proof over decorative orbs
- Pair with `paper-technical-frame` or `dark-premium` shells

## Avoid

Flat dark pages with accent but no container hierarchy; neon on every surface; generic equal card grids; mixing many unrelated accent colors.
