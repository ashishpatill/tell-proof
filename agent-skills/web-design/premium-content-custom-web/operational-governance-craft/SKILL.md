# operational-governance-craft

## Story beats
1. Operational problem + one restrained product visual
2. Verified/declared metrics only
3. Capabilities as workflows with permissions
4. Governance (approval, audit, exception, rollback) before the ask
5. Qualified demo handoff

## FAQ must cover
Ownership, data handling, integrations, review, failure/rollback, procurement

Avoid glowing AI orbs, neon gradients, unsupported security theater.
