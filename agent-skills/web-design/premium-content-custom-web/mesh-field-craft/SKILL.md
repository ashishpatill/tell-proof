# mesh-field-craft

## System recipe (complete)

1. Foundation: near-black with cool undertone (from mood tokens, not hardcoded blue lock)
2. Hero shell: large rounded container, subtle edge, darker inner fill
3. Mesh field: canvas/WebGL veil **inside** the shell
4. Type: high-contrast headlines, muted support
5. Nav: compact translucent pill optional
6. Nodes: sparse callouts + connectors (pairs with `wireframe-annotation-craft`)
7. Structure: rails, corner squares, numeric markers
8. CTAs: one solid + one ghost
9. Motion: slow mesh drift; pause offscreen; static under reduced motion

## Tell

- Prefer `dark-premium` + `container-tech-shell` + static CSS mesh approximation in engine
- Full procedural mesh only when site kind / brief asks for infrastructural depth
- Never let mesh wash CTA contrast
