## Constraints that are not “skips”

These are **shipping defaults**, not ignored knowledge:

1. Content readability and contrast beat bloom
2. One motion system; pause when offscreen / `document.hidden`
3. `prefers-reduced-motion` → static frame or omit
4. Brand accent from tokens — never hardcode a purple/blue family
5. Glass/particles/beams are sectional accents, not page-wide screensavers
6. Never invent logo walls or fake proof

Always end with **Taste Controls** the human can adjust.
