# editorial-chapter-craft

1. Let proof or selected work earn attention before explaining the maker
2. Treat each major band as a chapter with its own surface weight
3. Services/capabilities as large semantic headings, not identical cards
4. One unmistakable close — not an appended afterthought
5. Motion: once-only reveals; no scroll hijack; ≤1.02 media scale on focus

Avoid inventing clients, awards, or metrics. Prefer declared features as chapter titles.
