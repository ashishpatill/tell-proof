# pricing-decision-craft

Help visitors **choose**, not just see prices.

## Rules
1. Lanes derive only from declared capabilities (Core / Standard / Full slices)
2. One recommended lane — quiet flag, not yelling
3. Monthly/Annual cadence control with annual savings callout
4. Risk note under the table (cancel/pause without surprise lock-in)
5. FAQ deep-links ambiguous limits (via conversion-landing-craft)

## Avoid
- Invented plan names disconnected from features
- Hidden overages
- Fake social proof next to pricing
