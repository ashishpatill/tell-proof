# agency-minimal-grid

Full sister patterns: `nested-frame-craft`, `image-first-fold`, `editorial-chapter-craft`, `agency-quality-site/DESIGN_RIGOR.md`.

## Visual target

- Multi-column discipline with large open spans and intentional alignment — not a dashboard.
- Oversized headlines (tight tracking, strong line breaks) as the primary anchor.
- Tiny uppercase utility labels / meta in adjacent columns — never competing with display.
- Light neutrals, thin separators, quiet image frames; accent as punctuation only.
- Imagery as large panoramic or architectural blocks — not card-heavy galleries.

## Implementation

- Wide max-width shell; column placements feel engineered.
- Confident scale contrast: display huge → body calm → meta microscopic.
- CTAs understated (thin borders / neutral fills / small labels) — not loud pills.
- Motion: masked reveals, slow image settle, restrained hover only.
- Background atmosphere, if any, stays extremely quiet.

## Avoid

- Repeated interchangeable cards as the whole story
- Heavy borders, big shadows, dense nesting
- Filling every gap — preserve intentional open space
- Mixing this lane with glass-everywhere or documentary brutalism in the same pass
