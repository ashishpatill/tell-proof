# paper-technical-frame

## Visual target
- Warm paper surfaces, not stark white
- Darker outer page field framing the content shell
- Thin brackets / rules; one restrained accent
- Calm motion only

## Avoid
- Flat white SaaS with no material
- Heavy vintage distressing
- Purple/glass spectacle shells
